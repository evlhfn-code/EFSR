# Open Questions

These are things the Discord logs don't settle yet. The calculator either asks you for the in-game value or labels its assumption. If you know the answer, update this note and the setting in `data/efsr-data.json`.

| Question | What the calculator does now |
|---|---|
| Where does the 25x Gold Egg boost apply inside `5 x log10(BE)`? | Multiplies the result. |
| Is Rebirth Cap Increase capped at 550 (menu) or uncapped (update #8)? | Default max 550; you can change it. |
| What does one level of Rebirth Cap Increase or Rebirth Boost do in numbers? | Shows cost only. |
| What counts as a "Prestige" for Prosperity (Rebirths, Ascensions or Retires)? | You enter the count. |
| Does the 10x diamond boost apply to Diamond Rain? | Assumes yes (1,500 per rain). |
| How does Rebirth Power grow between 25% and 30%? | Use your in-game value. |
| What are the modded Timelapse sizes (50 / 125 / 300 / 1K what)? | Listed as given. |
| How many Platinum Eggs does an Ascension give? | You enter your pending amount. |
| Does the 2018 re-creation have every Hero past Aang? | Lists all 54 from the wiki. |
| Have Dealer and box prices changed? | Shows original prices. |

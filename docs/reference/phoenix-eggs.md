# Phoenix Egg Reference

| Phoenix Egg | Effect | Next level costs |
|---|---|---|
| Earth | +1,000% x n^2 Black Eggs from Mutated Bosses. | n + 1 |
| Water | Easter Egg costs x 0.95^n (5% cheaper per level). | n + 1 |
| Fire | +100% damage per level (1 Gold Egg each). | 1 |
| Sound | +12.5% Idol Egg effectiveness per level (about -1 chicken per level). Boosted by Resonance. | n + 1 |
| Wind | +75% Hourglass Egg effectiveness per level (+22.5 s boss timer). | n + 1 |
| Acid | +50% King Cobra Egg effectiveness per level (-2.5x boss health). | n + 1 |
| Magnetism | +25% Radioactive Egg effectiveness per level (+18.75% mutation chance). | n + 1 |
| Electricity | +100% Scientist Egg effectiveness per level (+100x Eggception chance). | n + 1 |

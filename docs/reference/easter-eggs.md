# Easter Egg Reference

Costs are in Black Eggs, before the Water discount (x 0.95^Water). n is the current level.

| Easter Egg | Effect | Next level costs |
|---|---|---|
| Good Knight | +11% Damage / Sec per level. | 1 |
| AFK | +25% DPS while idle per level. Modded: idle starts after 15 s without attacking. | n + 1 |
| Demeaning | +15% damage to critical attacks per level. | n + 1 |
| Dragon | +20% Attack Damage per level. | n + 1 |
| Eggplant | +30% White Eggs from Fertilizer per level. | n + 1 |
| Faberge | +5% White Eggs dropped per level. | n + 1 |
| Newton | +50% White Eggs from Eggceptions per level. | n + 1 |
| Wonderland | +10% damage from Trophy bonuses per level. | n + 1 |
| Turtle | +0.01% DPS per attack (combo) per level. | about n^1.5 |
| Cactus | +2 s to Fertilizer per level. | 2^(n+1) |
| Garbage | Cuts farmer hire and upgrade cost by 99.99999999 x (1 - e^(-0.01n)) %. | 2^(n+1) |
| Hourglass | +30 x (1 - e^(-0.034n)) s boss timer (max +30 s near level 1,101). | 2^(n+1) |
| Idol | -8 x (1 - e^(-0.025n)) chickens per level (minimum 2). | 2^(n+1) |
| King Cobra | -5 x (1 - e^(-0.002n)) boss health multiplier (boss floor 5x). | 2^(n+1) |
| Ninja | +2 s to Nine-Tails Chakra Mode per level. | 2^(n+1) |
| Present | 100 x (1 - e^(-0.0025n)) % chance of 10x White Eggs. | 2^(n+1) |
| Radioactive | +75 x (1 - e^(-0.013n)) % Mutated Boss chance. | 2^(n+1) |
| Scientist | +9,900 x (1 - e^(-0.002n)) % Eggception chance (up to 100x). | 2^(n+1) |
| Super | +2 s to Super Saiyan per level. | 2^(n+1) |
| Treasure | +2 s to Treasure Hunt per level. | 2^(n+1) |
| Unstable | +2 s to Tornado per level. | 2^(n+1) |
| Volcano | +2 s to Battle Shout per level. | 2^(n+1) |

# Platinum Upgrade Reference

Ascend at farm level 300,000. Pending Gold Eggs count toward Platinum Eggs (patch #8).

| Upgrade | Max | Effect | Note |
|---|---|---|---|
| Rebirth Cap Increase | 550 | Raises the rebirth cap, helping unlock higher Black Egg earnings. | Menu shows MAX LEVEL 550; patch #8 says 'Rebirth Cap Increase egg is uncapped'. Check in game. |
| Rebirth Boost | 10 | Improves rebirth progression. |  |
| Level Skip | 40 | Skips farm levels to speed up progression. |  |
| Abundance | none | +1% Eggs, Black Eggs and Gold Eggs per level. |  |
| Prosperity | none | +2% Black Eggs per Prestige per level. | Community feedback: its bonus may not compound. Kept low. |
| Resonance | none | +2% Sound Egg effectiveness per level. |  |

Standard upgrades: n levels from current level L cost n x (2L + n + 1) / 2. Rebirth Boost: 2^(L+n) - 2^L. These match observed examples; not confirmed game source.
